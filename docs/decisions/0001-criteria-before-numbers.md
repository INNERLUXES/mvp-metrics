# 1. Criteria are written before the numbers

## Context

After an MVP launches, every number can be explained away: activation is low because the onboarding is new, retention is low because it is summer. The only protection is to decide what counts as success before seeing any result.

## Decision

- Targets live in a criteria file, not in command line options that are easy to change on the day.
- The tool has no built-in targets; the example file is marked as an example.

## Consequences

- The criteria file becomes part of the product's plan, versioned next to it, and the report is judged against it.
